# SmartDef - Упрощенное DeFi инвестирование

SmartDef - это Telegram Web App, который делает DeFi инвестирование доступным для обычных пользователей. Вместо сложного взаимодействия с множеством протоколов, пользователи просто выбирают стратегию и вносят средства.

## 🚀 Возможности

### Текущие функции
- ✅ **Выбор инвестиционных стратегий** (Консервативная, Умеренная, Агрессивная)
- ✅ **Портфель инвестиций** с отслеживанием доходности
- ✅ **Аналитика** с графиками и статистикой
- ✅ **Депозиты и выводы** средств
- ✅ **Telegram Web App** интерфейс

### Инвестиционные стратегии

#### 🟢 Консервативная (3-8% годовых)
- **Риск:** Низкий
- **Распределение:**
  - 60% - Стейблкоины (USDT, USDC, DAI)
  - 30% - Лендинг протоколы (Aave, Compound)
  - 10% - Ликвидность в крупных DEX
- **Протоколы:** Aave, Compound, Uniswap V3, Curve Finance

#### 🟡 Умеренная (8-15% годовых)
- **Риск:** Средний
- **Распределение:**
  - 40% - Стейблкоины
  - 35% - Лендинг и yield farming
  - 25% - Ликвидность в DeFi протоколах
- **Протоколы:** Aave, Compound, Yearn Finance, SushiSwap, Balancer

#### 🔴 Агрессивная (15-30% годовых)
- **Риск:** Высокий
- **Распределение:**
  - 20% - Стейблкоины
  - 50% - Yield farming и новые протоколы
  - 30% - Ликвидность в рискованных пулах
- **Протоколы:** Yearn Finance, SushiSwap, Balancer, Curve Finance, New DeFi Protocols

## 🛠 Техническая архитектура

### Frontend
- **HTML/CSS/JavaScript** - базовая структура
- **Telegram Web App API** - интеграция с Telegram
- **Chart.js** - графики и аналитика

### Backend (планируется)
- **Node.js/Express** - API сервер
- **Web3.js/Ethers.js** - взаимодействие с блокчейном
- **PostgreSQL** - база данных пользователей и транзакций
- **Redis** - кэширование и сессии

### DeFi интеграции (планируется)
- **Aave** - лендинг протокол
- **Compound** - лендинг протокол
- **Uniswap** - DEX ликвидность
- **Curve Finance** - стейблкоин пулы
- **Yearn Finance** - yield farming
- **SushiSwap** - DEX и yield farming

## 💡 Бизнес-модель

### Комиссии
- **Комиссия за управление:** 0.5-1% годовых
- **Комиссия за успех:** 10-20% от прибыли
- **Комиссия за транзакции:** 0.1-0.3%

### Целевая аудитория
- **Новички в DeFi** - не знакомы с техническими деталями
- **Занятые профессионалы** - нет времени на активное управление
- **Консервативные инвесторы** - предпочитают стабильность
- **Крипто-энтузиасты** - хотят упростить процесс

## 🚀 Запуск проекта

### Локальная разработка
1. Клонируйте репозиторий
2. Откройте `index.html` в браузере
3. Для тестирования Telegram Web App используйте BotFather

### Продакшн деплой
1. Настройте Telegram Bot через BotFather
2. Разверните статические файлы на CDN
3. Настройте backend сервер
4. Подключите DeFi протоколы
